# Умный газовый счётчик на ESP8266 и ESPHome

🇩🇪 [Deutsch](README.md) · 🇷🇺 Русский

Считывает показания обычного немецкого мембранного газового счётчика (например, G4 RF1) с помощью датчика Холла и передаёт в Home Assistant показания счётчика, расход в кВт·ч, текущий расход газа и мощность.

Подробное видео (на немецком): https://youtu.be/yp7ZDe6VlVM

## Что нужно
- Home Assistant с ESPHome
- Wi-Fi рядом со счётчиком
- Газовый счётчик с магнитом в последнем ролике (например, G4 RF1, 1 импульс = 0,01 м³)
- ESP8266, например Wemos D1 mini
- Плата с датчиком Холла, например KY-024 (питание 3,3 В, не 5 В)

## Файлы
| Файл | Вариант |
|---|---|
| `00-gasmeter.yaml` | Аналоговый: датчик Холла на A0, импульсы считаются по порогу напряжения |
| `gasmeter-v1-simple.yaml` | Цифровой: дискретный выход датчика на D1 |
| `gasmeter-v2.yaml` | Аналоговый (A0) и цифровой (D1) одновременно для сравнения, нужен линейный датчик 49E |
| `configuration.yaml` | Фрагмент для Home Assistant: стоимость в €, счётчики за день/неделю/месяц |
| `dashboard.yaml` | Готовая панель для Home Assistant |

## Подключение

```
 KY-024 / плата 49E          Wemos D1 mini
 ┌──────────────┐            ┌──────────────┐
 │ +  (VCC) ────┼────────────┼── 3V3        │
 │ G  (GND) ────┼────────────┼── G          │
 │ A0 (аналог) ─┼────────────┼── A0         │   аналоговый вариант / v2
 │ D0 (цифра) ──┼────────────┼── D1         │   вариант v1 / v2
 └──────────────┘            └──────────────┘
```

- Датчик питать **от 3,3 В**, иначе на вход ESP может попасть до 5 В.
- Отдельный датчик 49E (плоской стороной к себе): вывод 1 = VCC, вывод 2 = GND, вывод 3 = выход → A0.
- Датчик установить в углубление под последним роликом: там мимо проходит магнит у цифры «0».

## Установка
1. В ESPHome создать новое устройство и вставить содержимое одного из YAML-файлов.
2. В файл ESPHome `secrets.yaml` добавить:
   ```yaml
   wifi_ssid: "..."
   wifi_password: "..."
   api_key_gasmeter: "..."   # новый ключ: https://esphome.io/components/api.html
   ota_gasmeter: "..."
   ```
3. Проверить параметры в разделе `substitutions`:
   - `imp_ratio`: объём на один импульс в м³ (указан на счётчике, например «1 imp = 0,01 m³»)
   - `threshold_upper` / `threshold_lower`: пороги срабатывания для аналогового варианта, см. калибровку
4. Прошить. Устройство появится в Home Assistant в разделе *Настройки → Устройства и службы → ESPHome*.

## Калибровка

### Аналоговый вариант (`00-gasmeter.yaml`, `gasmeter-v2.yaml`)
1. У датчика ADC временно поставить `internal: false` (в `00-gasmeter.yaml` стоит `true`), чтобы «GasMeterAnalogInput» был виден в Home Assistant.
2. Включить расход газа (отопление или горячая вода) и посмотреть по графику, как меняется напряжение, когда «0» на последнем ролике проходит мимо датчика. Записать минимальное и максимальное значение.
3. Рассчитать пороги:
   - середина M = (min + max) / 2, размах H = max − min
   - `threshold_upper` = M + 0,1 × H
   - `threshold_lower` = M − 0,1 × H

   Пример: min 0,520 В, max 0,560 В → M = 0,540, H = 0,040 → upper 0,544, lower 0,536.
4. Разница между upper и lower — это гистерезис. Слишком маленький — импульс считается дважды, слишком большой — импульсы пропускаются.
5. После настройки снова поставить `internal: true`, если значение больше не нужно.

Примечание: на ESP8266 ESPHome показывает напряжение прямо на входе чипа (0–1,0 В). На D1 mini стоит делитель, который превращает 3,2 В на выводе A0 в 1,0 В. Поэтому значения такие маленькие.

Если при большом расходе импульсы пропускаются, уменьшить `update_interval` у датчика ADC с `2s` до `500ms`.

### Цифровой вариант (`gasmeter-v1-simple.yaml`)
1. Покрутить потенциометр на KY-024, пока светодиод на плате не будет загораться ровно тогда, когда «0» проходит мимо датчика, а в остальное время не гореть.
2. `delayed_on` (от 50 мс до 1,5 с) подавляет дребезг. Если импульсы считаются дважды, увеличить значение.

### Проверка
Ввести показания счётчика (см. ниже), израсходовать несколько м³ и сравнить с механическим счётным механизмом.

## Настройки в Home Assistant
На странице устройства в разделе **Конфигурация**:

| Объект | Значение |
|---|---|
| **Zählerstand setzen** | Текущие показания газового счётчика в м³. Дальше счёт продолжается с этого значения. |
| **Zustandszahl** | Коэффициент приведения из счёта за газ, по умолчанию 0,95 |
| **Brennwert** | Теплота сгорания из счёта за газ в кВт·ч/м³, по умолчанию 11,2 |
| **gasmeter Neustart** | Перезагрузка ESP |

кВт·ч = м³ × Zustandszahl × Brennwert

## Датчики
| Объект | Единица | Значение |
|---|---|---|
| GasverbrauchAd / GasverbrauchPuls | м³ | Показания счётчика, совпадают с механическим счётчиком |
| Gasverbrauch-kWh | кВт·ч | Энергия, для панели «Энергия» |
| Gas Durchfluss | м³/ч | Текущий расход, считается по интервалу между двумя последними импульсами |
| Gas Leistung | кВт | Текущая мощность котла |
| gasmeter WLAN Signal | дБм | Уровень Wi-Fi у счётчика, лучше −75 дБм — хорошо |
| gasmeter Uptime | с | Время с последней перезагрузки |
| gasmeter IP, ESPHome Version | – | Диагностика |

О **расходе**: при 0,01 м³ на импульс и малой мощности импульс приходит раз в несколько минут. Поэтому значение — это среднее за последний интервал между импульсами. Если следующий импульс задерживается, значение уменьшается. Через 5 минут без импульсов показывается 0 (`flow_timeout_ms`).

## Панель управления (Dashboard)
В `dashboard.yaml` готовая панель (только стандартные карточки, HACS не нужен):
1. *Настройки → Панели → Добавить панель → Новая панель с нуля*
2. Открыть панель → карандаш (Изменить) → три точки → *Редактор YAML*
3. Вставить содержимое `dashboard.yaml` и сохранить

## Панель «Энергия»
*Настройки → Панели → Энергия → Добавить потребление газа* и выбрать «GasverbrauchAd» (м³) или «Gasverbrauch-kWh».

## Сохранение показаний
Показания хранятся во флеш-памяти и сохраняются после перезагрузки и отключения питания. Чтобы беречь флеш, запись происходит не чаще чем раз в 10 минут (`flash_write_interval`). После отключения питания может не хватать импульсов максимум за 10 минут. Время от времени сверяйте показания со счётчиком и при необходимости вводите их заново.

После первого ввода показаний значения один раз резко вырастут. Счётчики из `configuration.yaml` после этого обнулить действием `utility_meter.calibrate` (значение 0).

## Поиск неисправностей
| Проблема | Решение |
|---|---|
| Ничего не считается | Посмотреть напряжение «GasMeterAnalogInput», заново откалибровать пороги. В цифровом варианте настроить потенциометр. |
| Импульсы считаются дважды | Увеличить разницу между upper и lower или увеличить `delayed_on` |
| Пропуск импульсов при большом расходе | Уменьшить `update_interval` у ADC |
| Устройство часто офлайн | Проверить уровень Wi-Fi, при необходимости поставить репитер |
| Ошибка компиляции в `ota` или на выводе D1 | Обновить ESPHome, файлы рассчитаны на ESPHome начиная с 2024.6 |
